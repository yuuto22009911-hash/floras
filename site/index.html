A FLOWER, AS DATA

花は、構造である。HANA WA, KOUZOU DEARU

花弁の数、反り、切込みの深さ、雄蕊の半径。 ─ 花の見え方を決める要素を pure data で宣言すれば、拡大も色替えも量産も無料。 Tailwind が CSS に対して提供したものを、Floras Bloom は装飾フローラル SVG に対して提供する。

01

全構文を日本語で。

キーワード・識別子・色・単位・コメントすべて日本語。 アルファベットを 1 文字も使わない。 花 さくら { 花弁数 5; 大きさ 240; }

02

知覚色のみ。

16 進色を意図的に廃止し、OKLCH (知覚色(0.85 0.10 12)) と色見本の 2 通りに統一。 混色も知覚均等空間で計算され、ブランド色のグラデが綺麗。

03

決定論的。

散らす(scatter) には 種(seed) 必須。同じ .bloom は bit-identical な SVG を出す。 snapshot test がそのまま使える。

04

依存ゼロ。

Python 標準ライブラリのみ実装。Pyodide 互換の pure Python wheel として配布。 ブラウザにそのまま乗る。

PLAYGROUND

今すぐ、ブラウザで。RIGHT NOW, IN YOUR BROWSER

バックエンド不要・インストール不要。 Pyodide でブラウザだけで Python が動き、Floras Bloom がそのまま走る。 左で書いて、右に SVG が出る。⌘+Enter で再描画。

※ Pyodide の初回ロードに 5〜10 秒かかります。 ステータスが「● live」になったら描画可能です。

CAPABILITIES

4 つの動詞だけで、
花の世界を作る。

花を 作り、束ね、散らし、ひとまとまりにする ─ Floras Bloom にはこの 4 つの動詞しかない。

花BLOOM

1 つの花の構造をパラメトリックに宣言する。花弁数・反り・切込・雄蕊・茎・葉。

花 さくら { 花弁数 5; 大きさ 240; 花弁切込 0.45; 色 春.桜色; }
花束BOUQUET

複数の花を 1 つのキャンバスに配置。位置ごとに大きさ・色をオーバーライド可能。

花束 ヒーロー { 画布 1200 × 630; 置く さくら に 中央; 置く ゆり に (380, 320); }
散らすSCATTER

procedural に量産。種(seed) 必須で同じ入力は同じ出力。手描き感を量産できる。

散らす { 元 かべん; 数 60; 領域 画布; 大きさ 16..56; 種 42; }
模様MOTIF

「花 + 蕾 + 葉」のような複合要素を 1 単位で再利用。置く / 散らす から呼べる。

模様 ひとえだ { 置く さくら に (0, 0); 置く つぼみ に (-50, -30); 置く つぼみ に (45, 35); }

SHOWCASE — 一葉の作品

十二花暦。JŪNI KAREKI

1 つの .bloom ファイルから、12 種の花を Floras Bloom 言語のパラメータの組み合わせだけで描き分けた一葉。

つばき・うめ・さくら・ぼたん・すずらん・あじさい・あさがお・ひまわり・ききょう・こすもす・きく・すいせん。 すべて同じ geometry プリミティブから生まれ、花弁数 5〜24、反り 0.15〜0.9、切込 0〜0.45、並び 輪 / 螺旋 の組み合わせで「あ、その花だ」と分かる差を作っている。

CODE

1 行 1 行が、
そのまま意味になる。READ IT AS-IS

実際の .bloom ソースと、それが生成する SVG。Floras Bloom の言語表面はプログラムというより設計書に近い。 

※ 5 弁桜 ─ 切れ込みのある花弁
色見本 春 {
  桜色 知覚色(0.85 0.10 12);
  墨   知覚色(0.20 0.02 30);
  紅   知覚色(0.55 0.18 25);
}

花 さくら {
  花弁数 5;
  大きさ 240;
  色 春.桜色;
  花弁反り 0.4;
  花弁切込 0.45;
  雄蕊数 14;
  雄蕊色 春.紅;
  輪郭 春.墨 幅 1.2;
}

GET STARTED

はじめる。2 つの道

A — ブラウザだけで

すぐ書きたい人へ

Pyodide でブラウザだけで動きます。サンプルが 6 つ入っているので、好きな花を選んで描画ボタンを押すだけ。

open ./playground/index.html
# または:
python -m http.server \
  --directory playground 7879

B — ローカルで本格的に

CLI を入れる

Python 3.11+。外部依存ゼロ。floras render / preview / tokens の 3 サブコマンド。

git clone https://github.com/\
  yuuto22009911-hash/floras.git
cd floras
pip install -e .

floras render examples/さくら.bloom
floras preview examples/
floras tokens examples/ヒーロー.bloom \
  --format tailwind
